# SFT 评测深度分析

> 日期：2026-09-29。数据来源：Base 与 SFT-only 两档评测的 1,092 条轨迹、Jev 灰区判定、教材 parquet。所有数字可由脚本复现。

## 一、核心结果

| 指标 | Base 零样本 | SFT-only | 变化 |
|---|---:|---:|---:|
| 严格成功率（只认 Gold） | 39.2% | 60.7% | +21.5pp |
| 真实完成率（+Jev 完全满足替代品） | 52.8% | 72.1% | +19.3pp |
| easy / medium / hard（真实口径） | 66.3 / 55.0 / 42.2 | 81.0 / 73.5 / 65.2 | 全面提升 |
| 死循环率 | 10.1% | 6.2% | -3.9pp |
| 买错率 | 5.3% | 3.8% | -1.5pp |

## 二、行为效率：学到的不仅是买对，还有买快

| 行为指标 | Base | SFT |
|---|---:|---:|
| 成功轨迹平均步数 | 7.8 | 6.7 |
| 平均搜索次数 | 1.02 | **1.79** |
| 平均打开商品数 | 1.57 | 1.72 |
| 全轨迹平均步数 | 10.9 | 9.1 |

关键信号是**搜索次数接近翻倍**：Base 的模式是"搜一次 → 结果里挑一个买"（几乎从不重组关键词）；SFT 学到教材行为——首搜不理想就换词重搜、比较后再买。结合死循环率下降，可刻画为：SFT 把 Base 的"放弃式低效"（一次搜索后乱买或卡死）改造为"探索式高效"（重搜 + 比较 + 果断收手）。

## 三、任务级翻转矩阵

| 翻转方向 | 数量 | 特征 |
|---|---:|---|
| Base 败 → SFT 成（严格口径） | **291** | 难度分布 43E/157M/91H——hard 占比 31% 与总体占比一致，提升不靠捡简单题 |
| Base 成 → SFT 败（严格口径） | 56 | 集中于 medium（35）；41 条为部分满足购买 |
| 真实口径上升 | 272 | — |
| 真实口径下降 | **75** | — |

56 条"退步"深挖：41 条 partial 中 Jev 判 10 条 fully（真实口径未退步）、27 条 partial（买了近似商品）、4 条真买错。结论：SFT 的失败以"近似替代"为主，把 Base 能买对的题真正买错的极少——**无灾难性遗忘信号**。

## 四、SFT 残留死循环的病灶（68 条）

| 尾部模式 | 条数 | 机制 |
|---|---:|---|
| select_option 连续 6 次 | 12 | 反复点同一规格值被守卫拒绝，陷入重试执着 |
| 搜索-打开-返回 短环 | ~20 | 换词搜到的仍是同批商品，不肯回到已核验候选 |
| 其他混合环 | ~36 | — |

对应治疗方向：前者改进守卫回敬文案的明确性；后者正是 Teacher 收敛提示词第 7 条（"连续搜索无新增合格候选应回到已核验最优完成购买"）——学生未学透的规则，GRPO 阶段 reward 可自然施压。

## 五、画像效应：aligned 拖累两档一致，是真实现象

严格成功率排序（两档一致）：

| 条件 | Base | SFT |
|---|---:|---:|
| irrelevant | 41.7% | 63.3% |
| no_profile | 39.2% | 61.0% |
| **aligned** | **36.7%** | **57.6%** |

两档实验同排序、同幅度（约 5-6pp），排除噪声。**教材审计结果（本次新增）**：教材中替代品购买率按条件几乎无差异（no_profile 7.3% / aligned 7.7% / irrelevant 8.2%）——教材层面没有"aligned 的 Teacher 更多按画像买替代品"的证据，画像拖累的来源更可能在**决策偏好层面**（模型把画像偏好叠加进需求导致候选选择偏移）而非教材偏差。这是 GRPO 阶段可验证的假设：若 reward 施压后 aligned 差距收窄，则确认机制为决策层。

## 六、灰区救回率差异的解释

Base 灰区救回 53%（134/255）> SFT 40%（96/238）。Base 零样本"广撒网"更常碰巧买到完全满足的替代品；SFT 被教材导向精确命中 Gold，替代品空间收缩。绝对差距（52.8 → 72.1）说明精确化收益远大于替代品收缩损失。

## 七、后续行动建议

1. **GRPO 阶段重点施压**：死循环残留（第四节两类模式）与 aligned 画像鲁棒性（第五节假设）；
2. **领域短板**：家居家装 51% / 休闲娱乐 54% 显著低于最强域（运动户外 72%）——查这两域教材量与难度构成是否失衡；
3. **报告页**已含双口径三档对照与灰区明细（docs/data_report.html）。
