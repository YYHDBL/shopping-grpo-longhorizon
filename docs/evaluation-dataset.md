# Final-183 评测集

Final-183 是本仓库唯一用于模型横向比较的正式测试集。它从原始 Final-200 中剔除
17 道会扭曲模型能力判断的题，保留 183 个互不重复、与当前训练数据零 task-ID 重叠的
任务。

| 项目 | 值 |
|---|---|
| 任务清单 | `data/evaluation/tasks.jsonl` |
| 任务数 | 183 |
| 环境 / Reward | ShopSimulator v2.1 / Reward v3 |
| SHA-256 | `0d723a9fcf95d026c79c83b833eec2cb85aa49013da5f661cd1cb581aede773a` |
| 防泄漏 ID 清单 | `src/shopping_grpo/resources/blind_final_task_ids.json` |
| 详细更新记录 | [evaluation-updates.md](evaluation-updates.md) |

评测入口保持不变：`bash scripts/evaluate.sh NAME`。它默认读取上面的任务清单。
不要把 Final-183 得分与历史 Final-200 得分直接放在同一张排行榜中；分母不同。

## 为什么从 200 题变为 183 题

筛选标准是让每一道保留题都能公平地检验 Agent 对用户需求的理解、检索、核验、规格
选择和购买决策。以下问题会让模型被判错，即使其行为对用户而言合理，或使严格成功
在评分器中根本不可达。

| task_id | 剔除理由 |
|---:|---|
| 2352 | gold 规格里的转义字符与页面可选值不同，无法严格选中。 |
| 5904 | gold 规格的符号乱码，与页面可选值不同，无法严格选中。 |
| 11168 | gold 用 `?` 代替页面中的 `➕`，精确规格匹配无解。 |
| 11773 | 正确规格存在多套有效价格，Reward v3 无法解析最终价格。 |
| 12860 | 目标商品是飞利浦刷头，但品牌 gate 只从错误字段取证，目标本身也无法严格成功。 |
| 20345 | 用户未要求镜片折射率，gold 强加 1.54；同时多价格轴使 reward 不可验证。 |
| 5703 | 用户明确要 7 号机针，gold 强制 8 号。 |
| 21785 | 用户明确要 2XL，gold 强制 XL。 |
| 5510 | 用户要求 L 码两只装，gold 同时要求 `S-2只装` 与 L，规格语义冲突。 |
| 4786 | Query 未给尺码或颜色，gold 额外强制 `XL女175` 与红色。 |
| 19180 | 用户要求约 1.5 米车载线，gold 额外出现无意义的 `1mAh`。 |
| 4071 | 用户只要求 60 包胃药，gold 额外强制颜色。 |
| 3368 | 用户要求不超过 15cm，gold 却把 12cm 作为唯一硬规格。 |
| 6520 | “60 元出头”被当作不超过 60 元；gold 价 62 元，严格成功无解。 |
| 4925 | “300 多元”被当作不超过 300 元；gold 价 336 元，严格成功无解。 |
| 5475 | “4100 多元”被当作不超过 4100 元；gold 价 4158 元，严格成功无解。 |
| 6143 | “170 元上下”被当作不超过 170 元；gold 价 171 元，严格成功无解。 |

## 版本和维护规则

Final-183 是当前唯一的正式分母。任何未来改动都必须：

1. 先在 [evaluation-updates.md](evaluation-updates.md) 写明证据、影响 task ID 与
   新旧分母；
2. 同步更新任务清单、`metadata.json` 和 packaged blind-ID guard；
3. 运行 `tests/test_evaluation_dataset.py`，确认任务数、哈希和防泄漏清单一致；
4. 为历史轨迹按新 task ID 重算分母，但明确标注为“重算”，不得说成重新 rollout。

原始 Final-200 的任务清单和报告只作为审计归档背景，不再作为正式模型排行榜依据。
